**Multi-Site Restaurant Operations & Profitability Analysis**
This project analyzes Point of Sale (POS) and kitchen fulfillment data across four high-volume hospitality locations. By simulating 25,000 transaction records, I built a relational dashboard to track item-specific profitability against kitchen prep time variance. The analysis successfully isolated operational bottlenecks, revealing that a single high-complexity menu item was responsible for 33% of late-ticket revenue during peak dinner rushes, providing a clear target for labor optimization.

**Tools Used:** Python (Pandas), Google Colab, Power BI

**The Workflow:**
1. Python script generates 25,000 synthetic POS transactions incorporating peak-hour volume spikes and complex time-variance logic.
2. Data processing calculates unit economics (Revenue, COGS, Gross Profit) and fulfillment delays.
3. Interactive Power BI dashboard allows managers to filter by late orders, instantly identifying the specific menu items and locations causing service bottlenecks.
